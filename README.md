# Barcode Generator — Free Online Tool

**Barcode Generator.** Generate scannable EAN-13 and Code 128 barcodes with the official symbology tables, automatic check digit and SVG or PNG download. 100% in your browser. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/barcode-generator](https://miguelacm.es/tools/barcode-generator)

## ✨ Features

- **Official tables:** ISO/IEC 15417 Code 128 with mod-103 checksum and full stop pattern; GS1 EAN-13 with automatic check digit.
- **Print ready:** Vector SVG that scales losslessly or exact-resolution PNG for POS panels and print shops.
- **100% private:** Bar patterns are computed locally. Nothing is uploaded.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/BarcodeGenerator.git
cd BarcodeGenerator
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/barcode-generator
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/barcode-generator
```
